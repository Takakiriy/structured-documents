Folder_size_tree.ps1

使い方

Windows の PowerShell で実行します(Windows PowerShell 5.1 以降)。 指定したフォルダー配下を再帰的に走査し、フォルダーごとの合計サイズを インデント付きの一覧としてファイルへ書き出します。隠しファイルも数えます。 -Root には走査の起点とするフォルダーのパスを指定します。 -OutFile を省略した場合、走査対象のフォルダーではなく、 Folder_size_tree.ps1 自身が置かれているフォルダーの Folder_size_tree_out.yaml に出力されます。

コマンドの例

${HOME}\bin\Folder_size_tree.ps1 "C:\Users\me\Projects"

上記のように実行すると、${HOME}\bin\Folder_size_tree_out.yaml に 結果が書き出されます。別の場所に出力したい場合は -OutFile "パス" を追加してください。 出力したファイルの内容を、このページ上部のテキストエリアに貼り付けるか、 ファイルとしてドラッグ&ドロップしてください。

ソース

使い方

Linux や macOS の bash で実行します(zsh や sh ではなく bash で実行してください)。 find に -printf がない macOS などでは、ファイルのサイズを stat で読むので、Linux より遅くなります。 PowerShell 版と同じ形式で、フォルダーごとの合計サイズをファイルへ書き出します。 隠しファイルも数えます。第1引数には走査の起点とするフォルダーのパスを指定します。 --out-file を省略した場合、走査対象のフォルダーではなく、 folder-size-tree.sh 自身が置かれているフォルダーの Folder_size_tree_out.yaml に出力されます。 保存したあと chmod +x で実行権限を付けてください。

コマンドの例

${HOME}/bin/folder-size-tree.sh "/home/me/projects"

上記のように実行すると、${HOME}/bin/Folder_size_tree_out.yaml に 結果が書き出されます。別の場所に出力したい場合は --out-file "パス" を追加してください。 出力したファイルを手元のパソコンに持ってきて、このページで読み込んでください。
