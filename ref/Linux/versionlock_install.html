バージョン固定オプション --lock
二つのモードの処理順序
通常モードは最新を dnf install してから /etc/dnf/plugins/versionlock.list を生成し、固定モード用にコピーします。固定モードは配布された versionlock.list を置いてから dnf install し、固定どおりか検証します。両モードとも dnf install の前に配列確認、後にバージョン検証が入ります。
インストール スクリプト と TargetPackages 配列と versionlock.list の関係
スクリプトが dnf install する対象は、TargetPackages 配列にも載っている必要があり、無ければエラーになります。 TargetPackages 配列が versionlock.list の生成の母集団になるため、dnf install するのに配列へ足し忘れると、バージョン固定の検証もされません。
