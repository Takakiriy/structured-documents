DDDコンテキストマップの4パターン

自アプリのドメイン層に外部サービスのモデルを含めるか、依存方向はどうなるか

自ドメイン層に含む
含まない（外側）
依存の方向

1. Shared Kernel

共有モデルは両方のドメイン層に含まれる（相互依存）

2. Customer / Supplier

自（下流）が上流に依存。要望は上流に伝えられる

3. Conformist

外部のモデルをそのまま取り込む。自ドメイン層が外部に依存

4. Anti-Corruption Layer (ACL)

ACLが外部を呼び出し、自ドメイン層へ変換して渡す

まとめ

パターン ドメイン層に含むか 依存の方向
Shared Kernel 含む 相互依存
Customer / Supplier 含まない 自 → 上流
Conformist 含む 自ドメイン → 外部
Anti-Corruption Layer 含まない ACL → 外部 / ACL → 自ドメイン
