式を区別する5つの層についてのまとめ

議論で合意できた点と、未決着の点の整理です。

合意できた点

  • 式どうしの違いは、文字列・構造・役割・値の対応・具体的な値の5つの層に分けて整理できる。
  • 3×2 と 2×3 の構造の違いは、乗法の入力 (3, 2) と (2, 3) の違い、つまり二項演算としての乗法の始域の異なる元として、数学的体系の中に存在する。
  • その違いは、交換法則と代入原理により、値や結論には影響しない。つまりナンセンスである。体系の中に存在することと、ナンセンスであることは両立する。
  • 「一つ分」「いくつ分」という役割は、書き手と読み手の約束事として、式に込めることができる。
  • 約束事で役割を込めた場合は、式の順序の違いを気にしなければならない。

5つの層

上の層ほど細かく区別し、下の層ほど多くの式を同じとみなします。役割の層は、約束事があるときだけ現れる層なので点線で示しています。

構造の層の ×(3, 2) は、乗法への入力が (3, 2) であることを表します。役割の層は、入力の第1成分を一つ分、第2成分をいくつ分とする約束事の例です。値の対応の層の a+…+a は b 個の a の和で、3+3 は a = 3、b = 2 の場合にあたります。

層ごとの違い

層 3×2 と 2×3 a×b と a+…+a 3×2 と 10−4 状態
文字列 異なる 異なる 異なる 合意
構造 異なる 異なる 異なる 合意
役割 約束事があれば異なる ― ― 合意(約束事があるとき)
値の対応 同じ 同じ 異なる 合意
具体的な値 同じ (文字を含むため決まらない) 同じ 合意
ナンセンスの判定 ナンセンス ナンセンス ナンセンスではない 合意

ナンセンスの判定は、値の対応の層で行われます。

順序の違いを気にするか

約束事がない場合

3×2 と 2×3 の構造の違いは体系の中に存在しますが、交換法則と代入原理により、値や結論には影響しません。順序の違いはナンセンスで、気にしなければならない例はありません。

約束事で役割を込めた場合

書き手と読み手が、入力の第1成分を一つ分、第2成分をいくつ分とする約束事を共有すると、3×2 と 2×3 は伝える役割が異なります。式の順序の違いは気にしなければなりません。

補足(整理した側の解釈):2つの場合が両立するのは、代入原理が、値だけで真偽が決まる文脈で成り立つ原理だからです。約束事で役割を込めた文脈で 3×2 を 2×3 に置き換えると、値は保たれますが、役割は入れ替わります。

未決着の点

「一つ分」「いくつ分」をどのくらい明確に定義できるか

議論の相手は、役割を込める約束事について、一つ分・いくつ分の定義の明確さに疑義を示しています。どの程度明確に定義できるかは、文章題の場面によって変わる問題で、式の層の整理とは別の論点です。そのため、ここで議論をいったん区切っています。
